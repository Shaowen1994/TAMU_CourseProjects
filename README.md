## [CSCE633: Machine Learning](https://github.com/Shaowen1994/TAMU_CourseProjects/tree/main/CSCE633_MachineLearning)

**Project Name:** Facial Expression Recognition and Generation Using VGG and WGAN
**Instructor:** Dr. Atlas Wang
**Semester:** Fall 2019
**Collaborators:** Lianghao Zou
**Abstract:** Based on a novel database RAF-DB, we trained VGG-net to classify facial expressions and evaluate their separability. We then conditioned a WGAN on learned low-dimensional expression embeddings to generate realistic facial images for each expression.

## [ECEN766: Algorithms in Structural Bioinformatics](https://github.com/Shaowen1994/TAMU_CourseProjects/tree/main/ECEN766_AlgorithmsInStructureBioinformatics)

**Project Name:** Cross Modality (Seqeunce2Fold) Learning on Proteins
**Instructor:** Dr. Yang Shen
**Semester:** Spring 2020
**Collaborators:** None
**Abstract:** This project addressed protein fold classification using a simplified DeepSF model with fewer input features. Predicted secondary structures were incorporated as an additional modality to improve classification performance.
